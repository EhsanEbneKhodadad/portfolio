# Docker deployment implementation plan

Goal: Run the portfolio on Hamravesh or a Docker host with a small Node 24 production image and Hamravesh mirrors.

Architecture: Three build stages (base, dependencies, builder) plus a non-root standalone runner. Use the official Node image through HamDocker, npm through hmirror, and Alpine packages through hmirror. Enable standalone output only for Docker builds, preserving normal local and CI commands.

Constraints: Work in D:\PersonalProjects\portfolio. User subsequently authorized a commit. No push or deployment requested. Keep canonical domain, locale fonts/images, writing content, and preview protection. Never copy local environment or npm credentials into the build context.

- [x] Add Dockerfile, .dockerignore, opt-in standalone config and README commands.
- [x] Build the real image using the requested mirrors; validate non-root runtime, HTTP routes, canonical metadata, fonts, image optimization, and unknown URLs.
- [x] Run lint, types, unit tests and complete production browser suite.
- [x] Record verified results and any external mirror limitations.

Verification: Docker build --check passed without warnings. The real Linux image built from hub.hamdocker.ir/library/node:24-alpine; gcompat and all 437 npm packages installed from repo.hmirror.ir. Local Docker DNS initially failed for the mirror (and the official Alpine CDN). Public DNS resolved it; verification used a temporary build-only --add-host mapping. No DNS settings or IP addresses were hardcoded in project files.

The 78,225,914-byte image ran as UID 1000 under 1 CPU / 1 GiB limits. English/Persian/Turkish route, localized 404, canonical, font, optimized image, screenshot, static asset, robots, sitemap and browser-console checks passed. Default PORT=3000 and overridden PORT=3100 containers were healthy. Local environment files, npm credentials and test fixtures were absent.

Lint, typecheck, 6 unit tests, and all 26 browser tests passed. Runtime configuration review found no actionable issues. The first smoke assertion compared raw homepage canonical slash forms; URL-normalized comparison passed, with no app change needed. Temporary smoke containers removed after verification.
